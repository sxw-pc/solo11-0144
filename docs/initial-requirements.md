# 首版需求与边界

首版实现三个独立对象：带版本的步道拓扑与封闭公告、整改并独立复核的险情、受人数与时限约束的摆渡需求和班次。十个实际业务决定包含拓扑版本、封闭窗口、连通路线、险情等级、整改证据、复核身份、班次状态、席位竞争、离场时限与停运替代接续。

三条跨账路径：未解除险情即使公告开放也限制边；封路令原步行离场转成摆渡席位分配；迟到停运令已经可乘车的断路需求重新变为无保障。报告留存每次计算的需求人数、覆盖人数、路线和理由。

未实现的独立扩展包括跨景区步道接续、天气来源仲裁、无障碍坡度路线、夜间救援物资布点、巡检交接班责任、团队人数分批离场、施工许可联动、离线地图包发布。首版不预做这些状态或声称已支持。
